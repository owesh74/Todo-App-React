# React To-Do List App ✅

A clean, simple, and persistent to-do list application built with React and styled with Tailwind CSS. This app allows you to manage your daily tasks with ease, and your data is automatically saved to your browser's local storage.

## 🚀 Live Demo

**[View Live Application](https://oweshs-todo-app-react.vercel.app/)**

*Try the app without installation - your tasks will be saved locally in your browser!*

## Features ✨

- **Add Tasks**: Quickly add new tasks to your list
- **Edit Tasks**: Click the edit icon to modify an existing task
- **Delete Tasks**: Remove tasks you no longer need
- **Mark as Complete**: Check off completed tasks, which are visually struck through
- **Persistent Storage**: Your to-do list is saved in the browser's `localStorage`, so your tasks will be there when you return
- **Filter View**: A toggle allows you to show or hide completed tasks to keep your list clean
- **Responsive Design**: A clean and functional UI that works on different screen sizes

## Technology Stack 🛠️

- **Frontend**: React
- **Styling**: Tailwind CSS
- **Unique IDs**: UUID
- **Icons**: React Icons

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You need to have **Node.js** and **npm** (or yarn) installed on your computer.
- [Node.js Download](https://nodejs.org/)

### Installation

1. **Clone the repository** to your local machine:
   ```bash
   git clone https://github.com/owesh74/Todo-App-React.git
   ```

2. **Navigate into the project directory**:
   ```bash
   cd Todo-App-React
   ```

3. **Install the required npm packages**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm start
   ```

5. Open your browser and go to `http://localhost:3000` to see the application running.

## How to Use 📝

1. **Add a Task**: Type your task in the input field at the top and click the **"Save Work"** button
2. **Complete a Task**: Click the checkbox next to a task to mark it as complete
3. **Edit a Task**: Click the **edit icon** (📝). The task's text will appear in the input field for you to modify. Click **"Save Work"** again to save the change
4. **Delete a Task**: Click the **delete icon** (🗑️) to permanently remove the task
5. **Filter Tasks**: Use the **"Show Tasks You Finished"** checkbox to toggle the visibility of your completed tasks
